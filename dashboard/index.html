口径

投入和盈亏

  • 净投入：从外部进到钱包的钱（跨链转入、交易所提现、别人转入），按到账那一刻的价格折成美元，减去转出去的钱。开始追踪那天之前钱包里已有的东西按当时价格算作期初投入。
  • 累计盈亏（对比持有 USDC）= 现值 - 净投入。等于把每笔投入在到账时换成 USDC 一直拿着，现在会比实际少或多多少。
  • 现值：钱包里的 ETH、WETH、USDC、AERO，加上 LP 仓位里的币、未领取的 AERO 和未收取的手续费，全部按当前链上价格估值。空投垃圾币不计价。

每日收益

  • AERO 奖励 = 当天新增的（已领取 + 待领取），直接从 gauge 合约读取，领取时 1:1 到账，没有折损。按当天收盘时的 AERO 价格折算。
  • 交易手续费只在仓位没质押时产生（质押期间手续费归 veAERO 投票者），按当天收盘价折算。
  • 近 N 日年化 = 最近 N 个完整日（最多 7 天，不含今天）的收益合计 ÷ 这几天按时间加权的 LP 市值合计 × 365。按时间加权是说，仓位某天只在池子里待了一部分时间，就只按那部分时间算它的市值（待了半天就算一半），没开仓的时间不算。奖励份额随全池质押量剧烈波动，只作参考。

盈亏拆解

  • 带入资产涨跌：如果把带进来的币（ETH、USDC）原样拿着不动，现在值多少减去净投入，几乎全部来自 ETH 价格。
  • AERO 价格变动：AERO 奖励从赚到时到现在（或卖出时）的价格变化。
  • 无常损失与调仓：集中流动性仓位随价格被动换币（无常损失），加上自己兑换改变了持币结构后在价格变动中的盈亏，以及兑换的滑点和费用。由其余各项倒推得出，可正可负。

数据来源

  • 全部来自 Base 链上数据：钱包与仓位用存档节点读取每天收盘区块的状态；ETH 价格取 Uniswap v3 WETH/USDC 0.05% 池，AERO 价格取 Aero 上三个 AERO 池（vAMM AERO/USDC、CL200 AERO/USDC、CL200 AERO/WETH）的中位数，USDC 按 1 美元。
  • 流水由程序扫描钱包的全部链上交易得到，包括别人代发的交易（例如启用了 EIP-7702 的地址）；ETH 余额逐块核对到 1 wei。
