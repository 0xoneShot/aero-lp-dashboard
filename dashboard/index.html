口径

投入和盈亏

  • 净投入：从外部进到钱包的钱（跨链转入、交易所提现、别人转入），按到账那一刻的价格折成美元，减去转出去的钱。开始追踪那天之前钱包里已有的东西按当时价格算作期初投入。
  • 累计盈亏（对比持有 USDC）= 现值 - 净投入。等于把每笔投入在到账时换成 USDC 一直拿着，现在会比实际少或多多少。
  • 现值：钱包里的 ETH、WETH、USDC、AERO，加上 LP 仓位里的币、未领取的 AERO 和未收取的手续费，全部按当前链上价格估值。空投垃圾币不计价。

每日利息收益和每日盈亏

  • 利息收益：做 LP 当天赚到的利息 = 当天新增的 AERO 奖励（已领取 + 待领取，直接从 gauge 合约读取，领取时 1:1 到账，没有折损）× 当天收盘时的 AERO 价格，加上当天赚到的交易手续费（只在仓位没质押时产生，质押期间手续费归 veAERO 投票者）。AERO 按赚到那天的收盘价算，之后 AERO 的涨跌算进下面的价格部分：还在池子里待领的算进“池子里的 ETH 涨跌与无常损失”，领到钱包里的算进“钱包闲置资产等”。AERO 卖掉之前，这份利息还没有真正落袋。
  • 池子当日盈亏：只算放在池子里的那部分。= 当天收盘时池子里的价值（仓位里的币、未收取的手续费和待领 AERO）- 前一天收盘时的价值 - 当天新加进去的流动性 + 当天撤出的流动性、收取的手续费和领取的奖励（都按发生时的价格）。
  • 池子里的 ETH 涨跌与无常损失 = 池子当日盈亏 - 利息收益。包括池子里的 ETH 跟着价格涨跌、无常损失（价格变动时仓位被动地在 ETH 和 USDC 之间换币），以及待领 AERO 的价格变动。
  • 钱包闲置资产等 = 账户当日盈亏 - 池子当日盈亏。钱包里没放进池子的资产当天的涨跌，比如之前仓位跌出区间留下的 WETH、领出来还没卖的 AERO，再加上兑换的滑点和费用、Gas。
  • 账户当日盈亏 = 池子当日盈亏 + 钱包闲置资产等 = 当天收盘时的累计盈亏 - 前一天收盘时的累计盈亏，当天存入和取出的钱不算盈亏。各天加起来正好等于累计盈亏；开始追踪的第一天是从开始追踪到当天收盘的盈亏。今天是截至数据时间的数。
  • 区间：每天收盘时仓位的状态。在区间内；部分在区间内（有的仓位已经在区间外）；区间外（这时不赚利息）；无仓位（流动性已经撤出）。
  • 近 N 日年化 = 最近 N 个完整日（最多 7 天，不含今天）的利息收益合计 ÷ 这几天按时间加权的 LP 市值合计 × 365。按时间加权是说，仓位某天只在池子里待了一部分时间，就只按那部分时间算它的市值（待了半天就算一半），没开仓的时间不算。奖励份额随全池质押量剧烈波动，只作参考。

ETH 成本价

  • 两种情况算的都是：ETH 涨到什么价时，选中范围（一个钱包，或者合计）里钱包加池子的东西全部按市价卖掉，能拿回净投入加上累计利息收益（ETH 成本价），或者只拿回净投入（含利息回本价）。
  • 跌出区间后撤出、拿着 ETH 等：假设 ETH 跌到所有仓位区间的下沿以下，仓位全部变成 ETH，然后把流动性撤出来，连同钱包里原有的 ETH 和 WETH 一直拿着，其余东西不动。ETH 成本价 =（净投入 + 累计利息收益 - 其余东西的价值）÷ 这些 ETH；含利息回本价 =（净投入 - 其余东西的价值）÷ 同样的 ETH。算出来小于等于 0 就是任何 ETH 价格都已覆盖；手里的 ETH 太少（不到 0.05 个）时不算。现在价格还没跌破所有区间时（在区间内、区间之间或者涨过了区间），这组价格是跌出区间并撤出以后的情况，和现价比只是看距离，不代表现在卖出不亏；现在卖出看下面“如果一直留在池子里”那组，或者累计盈亏。已经没有仓位时，就是按钱包现在的样子算。
  • 如果一直留在池子里：不撤出，ETH 涨回区间时池子会按集中流动性的曲线边涨边卖 ETH，所以按整个持仓随 ETH 价格变化的真实曲线，求出总价值等于上面两个目标的 ETH 价格；ETH 价格再低也够的话，就是任何 ETH 价格都已覆盖。价格涨过区间上沿后池子全是 USDC，只有钱包里的 ETH 还跟着涨。这组是按现在的持仓算的，所以也是现在卖出要看的价格。
  • 共同假设：钱包里的 AERO、待领的 AERO 和其它代币都按今天的价格，USDC 等稳定币按 1 美元，不算卖出时的兑换手续费和 Gas。

盈亏拆解

  • 带入资产涨跌：如果把带进来的币（ETH、USDC）原样拿着不动，现在值多少减去净投入，几乎全部来自 ETH 价格。
  • AERO 价格变动：AERO 奖励从赚到时到现在（或卖出时）的价格变化。
  • 无常损失与调仓：集中流动性仓位随价格被动换币（无常损失），加上自己兑换改变了持币结构后在价格变动中的盈亏，以及兑换的滑点和费用。由其余各项倒推得出，可正可负。
